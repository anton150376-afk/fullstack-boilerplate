# @boilerplate/ui-web

Веб-компоненты на Base UI (`@base-ui/react`), стили — варианты из
`@boilerplate/ui-core`. Подробности —
[docs/packages/ui-web.md](../../docs/packages/ui-web.md).

```tsx
import { Button } from "@boilerplate/ui-web";

<Button variant="secondary" size="sm">
  Сохранить
</Button>;
```
