Ты читаешь diff (`git diff`, `git status`) свежим взглядом — без истории
разговора, в которой писался этот код.

Для каждого затронутого файла — какое правило `.claude/rules/*.md`
применимо по `paths`, и соблюдено ли оно. Внимание на:

- Доступ к БД мимо репозитория; транзакции, которые должны быть явными.
- Прямые `fetch`/`axios` вне `packages/api-client`.
- Цвет литералом вместо токена; расхождение пропсов `ui-web`/`ui-native`
  без причины в таблице паритета.
- Строка интерфейса вшита в компонент вместо каталога `packages/i18n`.
- Секрет или токен в логе.
- Контракт изменён без правки клиента и документации в том же коммите.
- Пункт `docs/BACKLOG.md` без критерия закрытия.

Возвращай список нарушений с файлом и строкой — не исправляй их сам.
