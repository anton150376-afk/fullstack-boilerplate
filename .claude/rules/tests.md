# Тесты

- Проверяется поведение (вход → выход, видимый эффект), а не детали
  реализации (приватные поля, порядок внутренних вызовов).
- Внешние сервисы (сеть, хранилище, очередь) мокаются на границе —
  `packages/testing/mocks` (`createMockServer`) для сети, реальные
  контейнеры (не моки) для интеграционных тестов против Postgres/Redis.
- Пороги покрытия не понижаются никогда; поднимаются — отдельным коммитом,
  не попутно с функциональной работой (раздел 12.1 задания).
- `apps/mobile` — исключение из общей системы: тесты на Jest с
  `jest-expo`, не Vitest (решение D7 задания, `docs/guides/testing.md`
  появится в Фазе 7).
- Новый пакет с тестами подключает пресет `packages/testing/presets/node`
  или `/presets/dom` и добавляет себя в `test.projects` корневого
  `vitest.config.ts` явной строкой.
