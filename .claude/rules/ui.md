# UI-компоненты

- Стили — только токенами из `packages/tailwind-config` (классы Tailwind,
  ссылающиеся на `@theme`-переменные). Цвет литералом (`#fff`, `red`) не
  писать — см. `docs/guides/styling.md`.
- Логика вариантов (`variant`, `size` и подобное) — в `packages/ui-core`,
  без привязки к платформе. `ui-web` и `ui-native` только рендерят по этим
  вариантам своими примитивами.
- Имя компонента и набор пропсов — одинаковые в `ui-web` и `ui-native`.
  Расхождение фиксируется в таблице паритета (`docs/packages/ui.md`) с
  причиной, а не молча.
- На бесплатной ветке Uniwind нет `hover:` и `group-*` — в общих
  примитивах `ui-native` их не использовать (решение D9 задания).
- `packages/admin-kit` — исключение из паритета: он веб-только, у него нет
  и не будет мобильной пары.
- Подробнее — `docs/packages/ui.md` (появится в Фазе 7, таблица паритета).
