> **Зачем читать:** какое правило подгрузится и когда.
> **Кому:** кто настраивает обвязку агента или не понимает, почему подгрузилось правило.
> **Последняя проверка:** 2026-10-08.

Каждый файл — фронтматтер `paths` (glob или список) плюс содержимое.
Правило подгружается в контекст только когда агент читает или пишет файл,
попадающий под `paths`; `git.md` — без `paths`, действует всегда (правила
коммитов не привязаны к конкретному каталогу).

| Файл                       | `paths`                                                   | О чём                                                                                  |
| -------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| [server.md](server.md)     | `apps/server/**`                                          | Вертикальные срезы, репозитории, транзакции, запрет логировать секреты                 |
| [contract.md](contract.md) | `packages/contract/**`                                    | Схема раньше обработчика, типы из схем, контракт+клиент+документация в одном коммите   |
| [client.md](client.md)     | `packages/api-client/**`, `apps/web/**`, `apps/mobile/**` | Только фабрика запросов, ключи кеша не руками, устаревшие API TanStack Query запрещены |
| [ui.md](ui.md)             | `packages/ui-*/**`                                        | Токены вместо литералов цвета, варианты в `ui-core`, паритет имён/пропсов              |
| [i18n.md](i18n.md)         | `packages/i18n/**`, `apps/web/**`, `apps/mobile/**`       | Каталоги, а не текст в компоненте; четыре формы числа; полифилы только в мобильном     |
| [admin.md](admin.md)       | `packages/admin-kit/**`, `apps/web/src/routes/admin/**`   | Реестр ресурсов, состояние в URL, права через поставщика                               |
| [storage.md](storage.md)   | `packages/storage/**`, `apps/server/src/**/files/**`      | Подписанная форма POST, проверка типа по сигнатуре, контрольные суммы AWS              |
| [queues.md](queues.md)     | `apps/server/src/**/queue*/**`                            | Идемпотентность, лимит повторов, воркер — отдельный процесс                            |
| [tests.md](tests.md)       | `**/*.test.ts`, `**/*.test.tsx`                           | Поведение, а не реализация; пороги не понижаются; `apps/mobile` на Jest                |
| [docs.md](docs.md)         | `**/*.md`                                                 | Структура страницы, запрещённые обороты, страница на каждый пакет                      |
| [git.md](git.md)           | — (всегда)                                                | Conventional Commits, ветки, один PR — одна работа, `GATE_ALLOW`                       |

Нумерация правил не используется — подтверждений, что она помогает
агентам, нет; ссылаться проще именем файла.
