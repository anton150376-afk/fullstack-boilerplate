# Git

- Коммиты — Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`,
  `refactor:`, `test:`).
- Ветки `feat/*`, `fix/*`, `chore/*` от `main`; прямые пуши в `main`
  закрыты (раздел 7.2 задания).
- Один pull request — одна связная работа. Несколько изменений схемы
  Prisma в одной работе — одна миграция, не несколько (раздел 7.3).
- `pnpm-lock.yaml` не редактируется руками и не сливается руками при
  конфликте — взять версию базовой ветки, повторить `pnpm install`.
- `GATE_ALLOW=<шаг>=<B-ID>` — аварийный клапан гейта, не постоянный обход:
  он требует существующий пункт `docs/BACKLOG.md` со статусом «Открыто»
  или «В работе» и пропускает ровно один названный шаг на один прогон.
  Клапан, прописанный в CI навсегда, — то же самое, что отключённый гейт.
- `git push --force` в `main` — не делать никогда.
