# Документация

- Структура страницы: блок «Зачем читать / Кому / Последняя проверка» →
  что это и где → как устроено → как работать → примеры → частые ошибки →
  ссылки на соседние страницы.
- Короткие предложения, активный залог, конкретные существительные.
  Термин вводится один раз и дальше не меняется. Сорок строк по делу
  лучше двухсот с повторами.
- Запрещённые обороты (гейт роняет, список —
  `scripts/docs-forbidden.json`, ведётся на русском): противопоставления
  вида «это не X, а Y»; пустые усилители («мощный», «современный»,
  «революционный», «бесшовный»); вводные пустышки («важно отметить»,
  «давайте разберёмся», «в современном мире»); эмодзи в заголовках;
  обещания без проверки («работает отлично», «проблем не возникнет»).
  Нужное исключение — комментарий `<!-- docs-check: allow <причина> -->`.
- Появился пакет или приложение — в том же коммите страница в
  `docs/packages/` или `docs/apps/` и запись в `docs/README.md`
  (`pnpm check:docs` проверяет оба условия).
- Относительные ссылки — только на существующие файлы; `pnpm check:docs`
  проверяет каждую.
- Дата «Последняя проверка» обновляется, когда страницу перечитали и
  подтвердили, не при любой правке по соседству.
