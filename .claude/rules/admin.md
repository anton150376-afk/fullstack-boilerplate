# Админка

- Экран строится из записи в реестре ресурсов (`defineResource`) — не из
  вручную собранной разметки списка/формы. Отклонение от генерации —
  через `overrides`, с причиной.
- Состояние таблицы (страница, сортировка, фильтры) живёт в параметрах
  поиска адресной строки (`validateSearch` со схемой Zod 4 напрямую, без
  адаптера — он нужен только для Zod 3). Ссылка на отфильтрованный список
  обязана открываться в том же виде у другого человека.
- Права проверяются через интерфейс поставщика прав, не прямыми `if
(user.role === ...)` в компоненте — до модуля M2 работает заглушка,
  разрешающая всё в разработке.
- `packages/admin-kit` — веб-только. Паритет с мобильным на него не
  распространяется и не проверяется (`scripts/check-parity.ts`, список
  исключений).
- Подробнее — `docs/guides/admin.md` (появится в Фазе 8).
