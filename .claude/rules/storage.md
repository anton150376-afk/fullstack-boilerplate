# Файлы

- Загрузка — только подписанной формой POST. Подписанный PUT не
  ограничивает размер (грабля 30 задания) — не использовать.
- Размер и тип ограничены политикой, входящей в подпись формы; хранилище
  само отвергает нарушение. Клиентскому заявленному размеру/типу не
  доверять.
- После загрузки сервер обязан проверить настоящий тип по сигнатуре
  файла, не по расширению или `Content-Type` из запроса.
- Контрольные суммы AWS SDK — `requestChecksumCalculation` и
  `responseChecksumValidation` в `"WHEN_REQUIRED"` (дефолт
  `"WHEN_SUPPORTED"` ломает S3-совместимые хранилища, не являющиеся AWS —
  грабля 29 задания).
- Адаптер хранилища — ровно четыре метода (`createUploadTicket`,
  `getDownloadUrl`, `head`, `delete`); не расширять интерфейс ради одного
  вызывающего места.
- Подробнее — `docs/guides/files.md` (появится в Фазе 4).
