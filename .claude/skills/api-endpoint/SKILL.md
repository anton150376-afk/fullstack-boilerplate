# api-endpoint

## Шаги

1. **Контракт.** Схема входа/выхода/ошибок на Zod 4 в домене
   `packages/contract` (см. `.claude/rules/contract.md`). Поля форм —
   `.meta({ widget, options })`, если маршрут используется админкой.
2. **Обработчик.** `@Implement` в контроллере Nest привязывает метод к
   процедуре контракта; guard'ы/pipe'ы/интерсепторы — как обычно
   (`.claude/rules/server.md`).
3. **Клиент.** Ничего руками не писать — `createTanstackQueryUtils`
   выдаёт `queryOptions`/`mutationOptions` из самого контракта
   (`.claude/rules/client.md`). Мутация объявляет инвалидацию.
4. **Веб и мобильное.** Вызов через общий хук в обоих интерфейсах. Один и
   тот же запрос в загрузчике маршрута веба и в компоненте мобильного —
   без дублирования кода.
5. **Тесты.** Контрактный тест (добавление маршрута без реализации на
   сервере должно ломать сборку или тест — проверить, что именно это
   делает), unit на обработчик, интеграционный при обращении к БД.
6. **Документация.** `docs/packages/contract.md` — запись в журнале
   изменений контракта с датой и причиной, если изменение ломающее.
7. **Гейт.** `pnpm verify`; OpenAPI (порождается из контракта) отдаёт
   новый маршрут.
