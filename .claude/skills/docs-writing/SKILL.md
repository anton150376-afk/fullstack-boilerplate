# docs-writing

Полный список правил — `.claude/rules/docs.md`, он подгружается
автоматически при редактировании `*.md`. Здесь — порядок действий.

## Шаги

1. **Блок-шапка.** `> **Зачем читать:**`, `> **Кому:**`,
   `> **Последняя проверка:** YYYY-MM-DD` — первые три строки любой
   страницы.
2. **Структура.** Что это и где → как устроено → как работать → примеры,
   которые можно скопировать и запустить → частые ошибки → ссылки на
   соседние страницы.
3. **Проверить на запрещённые обороты** — список в
   `scripts/docs-forbidden.json`. `pnpm check:docs` ловит их
   автоматически, но дешевле не писать их вовсе.
4. **Ссылки.** Относительные, на существующие файлы — `pnpm check:docs`
   проверит, но проще сразу писать верно.
5. **Регистрация.** Новая страница — строка в `docs/README.md` с кратким
   «о чём» и «кому».
6. **Коммит.** В том же коммите, что код, который страница описывает —
   не отдельным «docs follow-up».
