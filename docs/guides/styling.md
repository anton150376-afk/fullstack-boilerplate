> **Зачем читать:** добавить или поменять цвет/токен за один проход, не разбираясь в устройстве пакета.
> **Кому:** кто правит интерфейс и первый раз трогает палитру.
> **Последняя проверка:** 2026-10-08.

## Что это

Пошаговая инструкция. Устройство `packages/tailwind-config` и то, почему оно
так устроено — [docs/packages/tailwind-config.md](../packages/tailwind-config.md).

## Добавить новый токен цвета

1. Открыть `packages/tailwind-config/src/theme.css`.
2. Добавить строку в блок `@theme` вида:
   ```css
   --color-brand-450: oklch(0.67 0.135 258);
   ```
   Значение — обязательно `oklch(L C H)`.
3. Выполнить:
   ```bash
   pnpm --filter @boilerplate/tailwind-config generate:tokens
   ```
4. Закоммитить `theme.css` и перегенерированный `tokens.ts` вместе — тест
   `pnpm --filter @boilerplate/tailwind-config test` падает, если они разошлись.

## Куда токен попадает

| Потребитель                                           | Как берёт значение                             |
| ----------------------------------------------------- | ---------------------------------------------- |
| `apps/web` (DOM, классы Tailwind)                     | Напрямую из `theme.css` через CSS-переменную   |
| `apps/mobile` (Uniwind, классы Tailwind)              | Напрямую из `theme.css`, тем же путём          |
| `react-native-svg`, сырые стили RN, генераторы иконок | Из `tokens.ts` (hex) — `oklch` они не понимают |

## Поменять существующий цвет

То же самое: поменять значение в `theme.css`, перегенерировать `tokens.ts`,
прогнать тест. Семантические переменные (`--color-primary` и подобные)
ссылаются на шкалу — их трогать не нужно, если меняется сама ступень шкалы.

## Добавить семантическую переменную (новую роль, не новый цвет)

Семантические переменные в `theme.css` — отдельный блок под `:root` и
`:root[data-theme="dark"]`. Новая роль добавляется в оба селектора сразу,
со ссылкой на существующую ступень палитры:

```css
:root {
  --color-info: var(--color-accent-600);
}
:root[data-theme="dark"] {
  --color-info: var(--color-accent-300);
}
```

## Частые ошибки

- Значение цвета не в `oklch()` — генератор его не найдёт и тихо пропустит.
- Правка `tokens.ts` руками — тест упадёт с точным диффом, какая строка разошлась.
- Новая семантическая переменная только для светлой темы — в тёмной она
  останется неопределённой.
