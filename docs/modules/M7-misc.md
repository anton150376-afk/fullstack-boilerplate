## Назначение

Не модуль в смысле M1–M6 — список отдельных, не связанных друг с
другом решений, каждое отложено до конкретного внешнего условия
(выход пакета из 0.x, стабилизация ветки, появление функциональности).
Полный список — [ROADMAP.md](../../ROADMAP.md#m7-прочее).

## Границы

**Входит:** переход на `@tanstack/ai`, oRPC v2, TypeScript 7, оценка
Uniwind Pro, пересмотр формы/таблицы (TanStack Form, примеры shadcn
для TanStack Table v9).

**Не входит:** что-либо, требующее своей процедуры исследования и
ADR сверх проверки "вышло ли из 0.x/стало ли стабильным" — такие
решения становятся отдельным модулем M8+, не остаются здесь.
