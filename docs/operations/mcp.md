> **Зачем читать:** какие серверы MCP подключены и почему их не больше одного.
> **Кому:** кто настраивает рабочее окружение или хочет добавить ещё один сервер.
> **Последняя проверка:** 2026-10-08.

## Почему `.mcp.json` минимален

В неинтерактивных запусках (CI, фоновые агенты) серверы MCP подключаются
**без запроса подтверждения** — лишний сервер в `.mcp.json` расширяет
поверхность атаки незаметно для того, кто такой запуск настраивал.

## Что подключено

| Сервер                               | Зачем                                                                                                                             | Ключ                  |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- | --------------------- |
| `context7` (`@upstash/context7-mcp`) | Документация библиотек — сверка актуальных API вместо работы по памяти (главная проблема агента в этом стеке, раздел 3.8 задания) | `${CONTEXT7_API_KEY}` |

## Что не подключено, и почему

Эти серверы **полезны**, но не входят в `.mcp.json` по умолчанию —
подключаются вручную при необходимости (`claude mcp add ...`).

| Сервер     | Зачем может понадобиться                 | Условие подключения                                                                                                           |
| ---------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| PostgreSQL | Прямой просмотр состояния локальной БД   | Пользователь **только на чтение** — не давать агенту права на запись в боевые данные через MCP                                |
| Playwright | Интерактивная отладка сквозных сценариев | Только для отладки руками; в CI сквозные тесты запускаются обычной командой, не через MCP                                     |
| GitHub     | Работа с issues/pull request из агента   | Дешевле делать через `gh` (CLI уже есть в разрешениях `.claude/settings.json`) — отдельный сервер не даёт здесь ничего нового |

## Как добавить сервер

1. Решить, действительно ли он нужен **всегда**, а не в одной задаче —
   если это разовая отладка, использовать CLI напрямую, не трогать
   `.mcp.json`.
2. `claude mcp add <имя> ...` или правка `.mcp.json` руками.
3. Обновить таблицу выше в том же коммите.
