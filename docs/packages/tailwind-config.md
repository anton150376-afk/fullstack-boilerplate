## Что это

Единая палитра и базовые стили Tailwind ≥4.3.3 для `apps/web` и
`apps/mobile`. Источник правды — `packages/tailwind-config/src/theme.css`;
всё остальное (hex-зеркало, семантические переменные) выводится из него.

## Состав

| Файл                         | Назначение                                                                                                                                |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `src/theme.css`              | `@theme` с палитрой в `oklch` (6 семейств × 11 ступеней 50–950), радиусы, типографика, тени, семантические переменные светлой/тёмной темы |
| `src/base.css`               | Сброс и базовые стили для DOM — подключает только `apps/web`                                                                              |
| `src/tokens.ts`              | hex-зеркало палитры, **порождается** из `theme.css`                                                                                       |
| `scripts/generate-tokens.ts` | Парсит `--color-*` из `theme.css`, конвертирует в hex через `culori`, пишет `tokens.ts`                                                   |

## Как добавить токен

1. Добавить переменную в `@theme` в `theme.css` (цвет — обязательно в `oklch()`).
2. `pnpm --filter @boilerplate/tailwind-config generate:tokens`.
3. Если это цвет — он автоматически попадёт в `tokens.ts`; закоммитить оба файла вместе.

## Как токен доезжает до интерфейсов

- **Веб:** CSS-вход `apps/web` импортирует `@boilerplate/tailwind-config/theme.css`,
  затем `base.css`; классы Tailwind используют переменные напрямую.
- **Мобильное:** `global.css` Uniwind импортирует `@boilerplate/tailwind-config/theme.css`
  (без `base.css` — он для DOM). Директивы `@source` в CSS-входе каждого
  приложения перечисляют каталоги `packages/ui-web`/`packages/ui-native`
  **путями относительно самого CSS-файла** — Tailwind 4 не ходит по
  симлинкам pnpm (грабля 5 задания) и сканирует классы только из явно
  перечисленных каталогов.
- **`react-native-svg` и сырые стили RN:** импортируют `@boilerplate/tailwind-config/tokens`
  и берут hex напрямую — они `oklch` не понимают (грабля 8 задания).

## Почему hex — отдельный файл, а не ручной список

Ручной список рано или поздно разойдётся с палитрой в `theme.css`. Генерация
из одного источника плюс тест `src/tokens.test.ts` (сравнивает закоммиченный
`tokens.ts` с тем, что породил бы генератор прямо сейчас) держат оба
представления синхронными механически, а не по памяти.

**Проверено намеренным нарушением:** при правке `tokens.ts` руками без
перегенерации тест `tokens.test.ts` падает с точным диффом — какая строка
разошлась с `theme.css`.

## Частые ошибки

- Редактировать `tokens.ts` руками — тест это поймает, но проще сразу
  поменять `theme.css` и перегенерировать.
- Забыть `@source` в CSS-входе приложения — классы из `ui-web`/`ui-native`
  не найдутся, и Tailwind их не сгенерирует.
- Писать цвет не в `oklch()` — `generate-tokens.ts` требует именно `oklch(...)`
  в значении переменной и иначе эту строку не найдёт.
